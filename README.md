# El Raminel — ristorante pizzeria, Rovereto

Sito a pagina singola per El Raminel, Corso Bettini 15/A, Rovereto (TN).

HTML, CSS e JavaScript senza build e senza dipendenze: si pubblica così com'è (GitHub Pages, Netlify, qualunque hosting statico).

- `index.html` — la pagina
- `css/style.css` — stile (colori e caratteri in cima, come variabili)
- `js/main.js` — orario "aperto ora", scelta dell'impasto, tab del menu, richiesta di prenotazione via email
- `img/` — immagini ottimizzate; `img/logo/` logo ricostruito dall'insegna (SVG)
- `assets/` — foto originale dell'insegna e immagini d'archivio con i loro crediti
- `credits.md` — autori e licenze delle immagini

## Da confermare prima del lancio

- Menu e prezzi (sono verosimili, non quelli reali), dettagli degli impasti (ore, farine, supplementi)
- Significato di "raminel" (pentolino di rame) usato nel testo
- Orari: mar–dom 7:30–14:30 e 18:00–23:00, lunedì chiuso
- Foto dei piatti: sono di Unsplash, vanno sostituite con foto vere dei piatti
- La prenotazione apre un'email a larosa15@outlook.it: verificare che sia l'indirizzo giusto
